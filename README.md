# Placements-DSA

A curated collection of **Data Structures & Algorithms**, **coding interview problems**, and **placement preparation resources** implemented primarily in **Java**, with selected problems in **Python**.

The repository is organized by coding platforms and interview preparation tracks, making it suitable for students preparing for:

- Campus Placements
- Product-Based Companies
- Service-Based Companies
- Coding Assessments
- Technical Interviews
- Online Judges

# Overview

This repository serves as a personal DSA preparation library containing solutions from multiple competitive programming platforms and placement-oriented problem sets.

The solutions emphasize:

- Clean implementations
- Fundamental algorithms
- Interview-friendly coding style
- Practice for Online Assessments (OA)
- Company-specific preparation

Most Java files contain standalone executable programs that solve individual coding problems.

# Getting Started

## Clone the repository

```bash
git clone https://github.com/<your-username>/Placements-DSA.git
```

```bash
cd Placements-DSA
```

---

# Running Java Programs

Compile

```bash
javac FileName.java
```

Run

```bash
java FileName
```

Example

```bash
javac BinarySearch_704.java
java BinarySearch_704
```

---

# Running Python Programs

```bash
python filename.py
```

or

```bash
python3 filename.py
```

Example

```bash
python ReverseString.py
```
